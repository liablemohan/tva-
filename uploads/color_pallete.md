
## My strongest recommendation

I would **keep your navy `#0F3473`**, but I would **not use both brick red and rustic red together**.

The two reds are too close in hue and value to establish a clear color hierarchy. They also reinforce a somewhat traditional / earthy / craft aesthetic, whereas your target is **modernity + youth + innovation**.

Instead, I would use:

| Role                             | Color          | Hex       |
| -------------------------------- | -------------- | --------- |
| **Brand / Primary**              | Tvashta Navy   | `#0F3473` |
| **Background**                   | Warm Off-White | `#F5F3EE` |
| **Main Text**                    | Ink            | `#111827` |
| **Secondary Text**               | Slate          | `#667085` |
| **Innovation Accent**            | Electric Teal  | `#18A6A0` |
| **Warm Accent**                  | Terracotta     | `#D95D39` |
| **Subtle Surface**               | Cool Mist      | `#E8EBF0` |
| **Optional experimental accent** | Acid Lime      | `#C6F36B` |

### Why this works

**`#0F3473` — Navy**

Keep this as the unmistakable Tvashta color. It feels technical, intelligent and trustworthy without becoming corporate blue.

It should dominate:

**logo → navigation → primary UI → important labels → selected states → major graphic elements**

It has excellent contrast against your off-white background, so it can carry both branding and functional UI.

---

**`#F5F3EE` — Warm Off-White**

I strongly recommend keeping an **off-white rather than pure white**.

The page content deals with:

> material, ceramic, wood, metal, resin, physical objects, heritage, fabrication

so a slightly warm base helps connect the **digital system with physical materiality**. The original page already uses an ivory-ground concept, so this retains that strength while simplifying it. ([Tvashta Labs][1])

---

**`#111827` — Ink**

Use this instead of navy for most body text.

This is important.

If everything is `#0F3473`, your site starts looking like a branded corporate website.

Instead:

**Navy = identity**
**Ink = information**

That separation makes the interface feel more sophisticated.

---

**`#18A6A0` — Electric Teal**

This would be my biggest change.

Your existing green/teal direction is appropriate conceptually, but I would make it **cleaner and more digital**.

Use teal for:

* interaction states
* active process stages
* 3D object highlights
* scan / point-cloud visualization
* hover states
* progress indicators
* experimental UI

It represents the **innovation / technology** side of Tvashta.

---

**`#D95D39` — Modern Terracotta**

This is where I would replace your two reds.

I prefer:

### `#D95D39`

over

`#B55236`
`#A14A2F`

because it is brighter, clearer and more contemporary.

Your current reds are excellent **material colors**, but they read somewhat muted and historical. That could work beautifully for heritage objects but less effectively as the primary interface accent.

`#D95D39` gives you:

**earth + fire + fabrication + energy**

without looking like a traditional Indian craft brand.

So the visual relationship becomes:

**Navy → technology**
**Teal → innovation**
**Terracotta → making/materiality**

That is a much more useful semantic system.

### “Digital Material”

```text
NAVY       #0F3473
OFF-WHITE  #F5F3EE
INK        #111827
SLATE      #667085
TEAL       #18A6A0
TERRACOTTA #D95D39
MIST       #E8EBF0
```

Visual character:

**modern / intelligent / tactile / creative / technical**

This is the palette I would choose for the actual website.

The important thing is that the website should **mostly look monochromatic**.

Think roughly:

**70% off-white**
**20% ink / slate**
**7% navy**
**2% teal**
**1% terracotta**

The accents should feel like events happening inside a quiet interface.

If you want Tvashta to feel substantially more like a **creative technology startup**, add:

### `#C6F36B` — Acid Lime

Then:

```text
NAVY       #0F3473
OFF-WHITE  #F5F3EE
INK        #111827
TEAL       #18A6A0
TERRACOTTA #D95D39
LIME       #C6F36B
```

The lime should **not** become a normal UI color.

Use it almost like a signal:

**NEW**
**ACTIVE**
**LIVE**
**EXPERIMENT**
**03 / PROTOTYPE**

This gives the visual language a younger, more experimental quality.

It would pair particularly well with your site's ideas of **“Imagine,” “Prototype,” “Make,”** and interactive hero objects. ([Tvashta Labs][1])

# I would NOT do this

I would avoid making the site:

### Navy + red + gold + green + beige

That combination can very easily drift toward:

**heritage institution / luxury cultural brand / architecture museum**

which is close to the personality of the current page.

The content is already strongly heritage-oriented in places—for example, Station 01 discusses temples, monuments, sacred architecture and cultural artefacts, while later sections move into digital tools, additive manufacturing, materials and engineering. ([Tvashta Labs][1])

Your new visual identity should therefore communicate:

> **“We use advanced technology to work with culture, objects and physical reality.”**

rather than:

> **“We are a heritage organization using technology.”**

That distinction should guide the palette.

One particularly good trick would be to make the **grid and architectural geometry very low-contrast**, while allowing interactive elements to suddenly become saturated.

For example:

```text
background     #F5F3EE
grid           #D9DDE4
text           #111827
brand          #0F3473
interaction    #18A6A0
material       #D95D39
experimental   #C6F36B
```

This is much more effective for a minimal interface than putting saturated colors everywhere.

# The palette can also encode the Tvashta process

This is one place where I think the branding could become unusually coherent.

The page already has the four-stage process:

**01 Capture → 02 Imagine → 03 Prototype → 04 Make**. ([Tvashta Labs][1])

You can make the colors semantic:

```text
01 CAPTURE     Navy       #0F3473
02 IMAGINE     Teal       #18A6A0
03 PROTOTYPE   Lime       #C6F36B
04 MAKE        Terracotta #D95D39
```

That creates a visual language where the color itself communicates the process.

And importantly, you don't need to introduce four colorful sections.

Instead, the **entire site remains off-white / ink / navy**, while these four colors appear only when the corresponding state becomes active.

That would make your interactions feel much more intentional.

## My final recommendation

I would build the identity around this:

### **Tvashta Core**

**`#0F3473`**
Tvashta / intelligence / digital foundation

**`#F5F3EE`**
Canvas / physicality / warmth

**`#111827`**
Information / typography

**`#18A6A0`**
Innovation / interaction / technology

**`#D95D39`**
Material / making / energy

**`#C6F36B`**
Experiment / youth / future

The critical design principle is:

> **Keep the interface quiet; let the interaction introduce color.**

That fits the site's existing philosophy—each station has an interactive hero object, and the interaction itself is supposed to explain what Tvashta does. ([Tvashta Labs][1])

For the **minimal design you described**, this is considerably stronger than simply choosing a set of attractive colors.

If we continue this direction, the next useful step is to define a **full Tvashta design token system**—backgrounds, text hierarchy, borders, buttons, hover states, 3D object colors, station colors, gradients, and dark-mode equivalents—so the palette becomes directly implementable in CSS/Tailwind.
